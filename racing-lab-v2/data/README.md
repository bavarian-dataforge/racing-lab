# Streckendaten

`Nuerburgring.csv` ist unverändert aus der
[TUMFTM racetrack-database](https://github.com/TUMFTM/racetrack-database) übernommen und
steht unter **LGPL-3.0** (siehe `../../NOTICE.md` und `../../LICENSES/`). Kartengrundlage
© OpenStreetMap-Mitwirkende.

Spalten: `x_m, y_m, w_tr_right_m, w_tr_left_m` (Mittellinie und Breite je Seite in Metern).
Umrechnung für die Simulation: `python3 python/tools/build_nuerburgring.py`.
